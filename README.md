# bin_tree

Этот репозиторий содержит исходный код нелинейной структуры данных - бинарного дерева.

## Использование

Скачайте исходники этого проекта
```
git clone https://github.com/Tamik13/bin_tree
```

в include/bin_tree.h введите нужный вам тип данных и модификатор для вывода этого типа, например:

```
typedef double bin_tree_elem;
#define BNT_MDF "%.5g"
```

Теперь вы можете совершать с деревом следующие действия:

|Функция|Описание|
|-|-|
|bin_tree_assign|Создает пустое дерево|
|bin_tree_destroy|Удаляет дерево|
|bin_tree_insert|Создает вершину по переданному указателю|
|bin_tree_del|Удаляет вершину по переданному указателю|
|bin_tree_dmp|Дампит дерево в лог файл|

Пример программы написанной с помощью этого дерева в файле /src/main.cpp - бинарное дерево поиска.

Приятного использования!
